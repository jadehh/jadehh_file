##### 更新日志
###### V2.1.8.1 - 2025-07-29
###### 新增
* 线阵相机调试工具根据模式自动切换行频和高度
* 新增亮度参数
* 新增旋转角度参数，支持旋转角度的设置
* 自动验残服务支持多GPU配置
* 线阵相机新增水平镜像功能
##### 修改
* EIO输出配置成3路输出，解决现场EIO输出不稳定的问题
* 曝光参数修改成最大曝光和最小曝光参数，解决曝光参数不稳定的问题
##### 修复
* 修复线阵相机管理详情界面，编辑时使用默认的参数，不使用服务器的参数的bug
* 线阵相机拼接服务不在需要使用本机-net启动，解决线阵相机服务停止箱号服务也停止的bug
* 解决在Windows Server 2012 上无法打开的bug
* 修复在Linux上运行报错的bug
* 修复tabChange报错的bug
* 线阵相机的曝光参数变成最大曝光参数
* 修复EIO连接不上的bug
* 修复过卡详情界面无法查看的bug
