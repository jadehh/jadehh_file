##### 更新日志
###### V2.1.8.9 - 2025-07-24
###### 新增
* 线阵相机调试工具根据模式自动切换行频和高度
* 新增亮度参数
* 新增旋转角度参数，支持旋转角度的设置
* 自动验残服务支持多GPU配置
##### 修改
* EIO输出配置成3路输出，解决现场EIO输出不稳定的问题
* 曝光参数修改成最大曝光和最小曝光参数，解决曝光参数不稳定的问题
##### 修复
* 修复线阵相机管理详情界面，编辑时使用默认的参数，不使用服务器的参数的bug
* 线阵相机拼接服务不在需要使用本机-net启动，解决线阵相机服务停止箱号服务也停止的bug
